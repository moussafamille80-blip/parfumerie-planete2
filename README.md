# Planète 2 — Gestion de stock (parfumerie)

Application web statique (HTML/CSS/JS, sans build) : produits, entrées/sorties, prix fournisseur et prix de vente, marges, alertes de stock.

## Déploiement (GitHub + Vercel uniquement)
1. Créez un dépôt GitHub et poussez ces fichiers à la racine.
2. Sur vercel.com : **Add New → Project** → importez le dépôt → **Deploy** (aucun réglage : Framework « Other »).
3. Chaque `git push` redéploie automatiquement.

## Données
Enregistrées dans le navigateur (localStorage) : utilisez **Exporter** régulièrement pour sauvegarder, et **Importer** pour restaurer ou changer d'appareil.
